==============================================================================
 Validate_Passive_Tree.py  —  How to Use
==============================================================================

PURPOSE
-------
Run this script on your Inkscape passive tree SVG before exporting to JSON.
It performs four operations in one pass:

  1. RENUMBER   — assigns sequential indices (1, 2, 3 ...) within each prefix
                  group, in SVG document order.  You can leave any placeholder
                  number on NodeTag: lines and the script will fix them.

  2. RENAME IDs — sets each node element's SVG id to its final NodeTag
                  (dots replaced with underscores).
                  Connector inkscape:connection-start/end references are
                  updated automatically to match the new ids.

  3. COLOUR     — fills each node with a group colour.  All nodes sharing the
                  same second tag segment (e.g. Might, Fortitude) get the same
                  colour.  Colours are auto-generated across the colour wheel.

  4. VALIDATE   — confirms all final NodeTag values are unique.
                  Reports errors and aborts the save if any are found.


REQUIREMENTS
------------
Python 3.7+
lxml library:  pip install lxml

INKSCAPE SETUP — Setting a node description
--------------------------------------------
1. Draw a node using the Ellipse / Arc tool (E key).

2. Open Object Properties:
     Object menu > Object Properties   (Ctrl+Shift+O)

3. Fill in the Description field using NodeTemplate format.
   The NodeTag: line drives all four operations above:

     NodeTag:PassiveTree.Might.IncreasedArmour.0
     NodeType:Minor
     IsStartNode:false
     NodeName:Increased Armour
     NodeDescription:Grants increased armour rating.
     NodeIcon:/Game/...

   Tag format:
     PassiveTree.<Group>.<EffectName>.<Index>
     SkillTree.<SkillName>.<EffectName>.<Index>

   The last segment is the index placeholder — put 0 or anything, the script
   will replace it with the correct number.

4. To skip a shape entirely (decorative, placeholder, etc.) set the entire
   description to:

     ignore

   The script silently skips it.

Connector lines and all non-arc/ellipse shapes are ignored automatically.


NUMBERING
---------
Nodes are grouped by prefix (all tag segments except the last number).
Within each prefix group they are numbered 1, 2, 3 ... in SVG document order.

  Three nodes all tagged PassiveTree.Might.IncreasedArmour.0 become:
    PassiveTree.Might.IncreasedArmour.1
    PassiveTree.Might.IncreasedArmour.2
    PassiveTree.Might.IncreasedArmour.3

Different prefixes are numbered independently:
  PassiveTree.Might.IncreasedArmour.1  and  PassiveTree.Might.Core.1  are both valid.


ELEMENT ID RENAMING
-------------------
Each node's SVG element id is set to its NodeTag with dots replaced by underscores:
  NodeTag:  PassiveTree.Might.IncreasedArmour.1
  SVG id:   PassiveTree_Might_IncreasedArmour_1

Any Inkscape connector lines whose connection-start or connection-end referenced
the old id are updated automatically — connections are not broken.
