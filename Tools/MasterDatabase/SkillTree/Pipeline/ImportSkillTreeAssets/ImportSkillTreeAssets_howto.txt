==============================================================================
 import_skill_tree_assets.py  —  How to Use
==============================================================================

PURPOSE
-------
Runs inside Unreal Engine's built-in Python console.
Reads a skill tree JSON file and creates or updates UFP_SkillTreeNodeData
data assets in the UE Content Browser — one asset per node.

REQUIREMENTS
------------
  Unreal Engine 5.7 with Python scripting enabled.
  Enable: Edit > Plugins > Python Editor Script Plugin

------------------------------------------------------------------------------
HOW TO RUN
------------------------------------------------------------------------------

1. Open the UE Output Log:
     Window > Developer Tools > Output Log

2. Change the console dropdown from "Cmd" to "Python".

3. Copy and paste the block for the tree you want to import:

  import import_skill_tree_assets as importer; importlib.reload(importer)

------------------------------------------------------------------------------
WHAT GETS CREATED / UPDATED
------------------------------------------------------------------------------

For each node in the JSON one UFP_SkillTreeNodeData data asset is created
(or updated if it already exists) at:

    <output_folder>/<NodeTag with dots replaced by underscores>

Example:
    /Game/.../Nodes/Might/PassiveTree_Might_IncreasedArmour_1

Properties set automatically:
    NodeTag, NodeType, IsStartNode, NodeName, NodeDescription,
    NodeIcon, NodePosition, ConnectedNodeTags

Effects (TInstancedStruct array) CANNOT be set via Python.
After import, open each data asset and add effects manually
using the Effects array in the Details panel.

------------------------------------------------------------------------------
AFTER IMPORT
------------------------------------------------------------------------------

1. Open each newly created data asset and fill in the Effects array.

2. Assign all generated assets to the NodeDataAssets array on your
   tree widget BP subclass (e.g. WBP_MightTree defaults panel).

------------------------------------------------------------------------------
WORKFLOW — FULL PIPELINE
------------------------------------------------------------------------------

1. Design tree in Inkscape, set node descriptions using NodeTemplate.txt.
2. Validate and renumber:
     python Validate_Passive_Tree.py <TreeFolder>\<TreeName>.svg
3. Export JSON:
     python svg_to_skilltree_json.py <TreeFolder>\<TreeName>.svg
4. Add C++ gameplay tags:
     python import_tree_tags.py <TreeFolder>\<TreeName>.json
5. Rebuild in Visual Studio / UE.
6. Run this importer in UE Python console (see above).
7. Add Effects to each asset in the Details panel.
