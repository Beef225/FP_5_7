==============================================================================
 import_tree_tags.py  —  How to Use
==============================================================================

PURPOSE
-------
Reads a skill tree JSON file and registers any missing tags in one pass:
  NodeTags           -> Config/Tags/SkillTreeNodeTags.ini  (restart the editor; no rebuild)
  SkillPassive tags  -> FP_GameplayTags.h / .cpp            (rebuild)
  Gated stat tags    -> FP_GameplayTags.h / .cpp            (rebuild)
Rules for which tags go where: Tools/GameplayTags_README.md

Run after exporting the JSON from the SVG.
Tags that already exist in the singleton are skipped automatically —
safe to run multiple times on the same file.

REQUIREMENTS
------------
Python 3.8+  (no extra packages)
add_gameplay_tag.py must exist at:
  C:\Unreal\FP_5_7\Tools\add_gameplay_tag.py

WHAT GETS WRITTEN
-----------------
For each missing NodeTag the script inserts:

  Header (FP_GameplayTags.h):
    FGameplayTag PassiveTree_Might_IncreasedArmour_1;

  CPP (FP_GameplayTags.cpp):
    GameplayTags.PassiveTree_Might_IncreasedArmour_1 = UGameplayTagsManager::Get().AddNativeGameplayTag(
        FName("PassiveTree.Might.IncreasedArmour.1"),
        FString("Grants increased armour rating.")
        );

  The description string is taken from the NodeDescription field in the JSON.

Section behaviour:
  - The section name is inferred from the first segment of the first NodeTag
    (e.g. PassiveTree.Might.IncreasedArmour.1  ->  section "PassiveTree").
  - If that section already exists the new tags are appended to it.
  - If it does not exist a new // comment section is created automatically.
  - Use --section to override the inferred name.

WORKFLOW — FULL PIPELINE
--------------------------
1. Design tree in Inkscape, set node descriptions (see NodeTemplate.txt).
2. Validate:     python ValidatePassiveTree\Validate_Passive_Tree.py <svg>
3. Export JSON:  python SVGToJSON\svg_to_skilltree_json.py <svg>
4. Add tags:     python ImportTreeTags\import_tree_tags.py <json>     <- YOU ARE HERE
5. Rebuild in Visual Studio / UE.
6. Import assets in UE Python console (see ImportSkillTreeAssets_howto.txt).
