==============================================================================
 ATTRIBUTE TAG MAP  —  use these tags in EFFECT_STAT lines
 Format:  EFFECT_STAT:<AttributeTag>|<Op>|<Magnitude>

 EffectStatModifierOp is ALWAYS "Add" — every attribute below is designed to
 accumulate as a linear SUM of every contributing node (base value 0), with
 any percentage-style behaviour ("Increased X damage", AoE size, etc.)
 applied by the CONSUMING C++ code doing its own `1 + sum` math (e.g.
 ExecCalc_Damage.cpp, GetEffectiveSphereRadius) — never by GAS's own
 Multiply modifier op. EffectStatModifierOp IS a real, literal GAS op
 (confirmed via FP_SkillTreeImporter.cpp / FFP_NodeEffect_StatModifier) —
 setting it to anything but Add on one of these attributes actively breaks
 it (confirmed bug: an AoE.Multiplier node using Multiply collapsed to 0
 instead of contributing +10%, since GAS's Multiplicative op multiplies
 against the attribute's base value, which is 0 for every bonus-only
 attribute here). The (Op) column below is purely descriptive of how the
 summed value gets used downstream — it is not a menu to choose from.
==============================================================================
