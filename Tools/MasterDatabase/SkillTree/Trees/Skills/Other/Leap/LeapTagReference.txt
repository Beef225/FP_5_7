================================================================================
  LEAP — SKILL TREE TAG REFERENCE
================================================================================
  Each node data asset needs:
    NodeTag       →  SkillTree.Leap.GroupName.#      (node identity)
    Effect tags   →  SkillPassive.Leap.EffectName    (on each
                     FFP_NodeEffect_SkillPassive in the Effects array)

  The passive tag is written into PlayerState's SkillPassiveValues accumulator
  on commit, and read back by the ability at cast time.

  Skill class:  UFP_GA_Leap  (AbilitySystem/Abilities/Movement/FP_GA_Leap)
  Parent class: UFP_GA_MovementSkill → UFP_DamageGameplayAbility
================================================================================


--------------------------------------------------------------------------------
  EXTRA RANGE  (3 nodes)
--------------------------------------------------------------------------------
  Node tags    SkillTree.Leap.ExtraRange.1  →  .3
  Effect tag   SkillPassive.Leap.ExtraRange
  Magnitude    200.0 per node  (+200 cm / +2 m of leap distance per node)
  Routes to    UFP_GA_Leap::GetEffectiveRange — added to BaseLeapRange (1200 cm).
               Max range with all 3 nodes: 1800 cm (18 m).
  Connections  Linear chain. ExtraRange.1 is a start node (or gated by entry).


--------------------------------------------------------------------------------
  EXPLOSIVE LANDING  (1 node — Major)
--------------------------------------------------------------------------------
  Node tag     SkillTree.Leap.ExplosiveLanding.1
  Effect tag   SkillPassive.Leap.ExplosiveLanding
  Magnitude    1.0  (flag — any value >0 enables the explosion)
  Routes to    UFP_GA_Leap::ShouldDoExplosiveLanding / ApplyLandingExplosion.
               Explosion radius base: 400 cm, scaled by AoE attribute modifiers.
               Damage: uses DamageTypes map on the ability — set in BP defaults.
  Connections  Major node. Suggest gating behind ExtraRange.2 or as a standalone
               branch. ExplosiveLanding.1 can gate HeatCost.1.
  Notes        The node unlocks AoE damage on landing. DamageEffectClass and
               DamageTypes must be set in BP_GA_Leap defaults for damage to apply.


--------------------------------------------------------------------------------
  NO WINDUP  (1 node — Major, trade-off node)
--------------------------------------------------------------------------------
  Node tag     SkillTree.Leap.NoWindup.1
  Effect tag   SkillPassive.Leap.NoWindup
  Magnitude    1.0  (flag — any value >0 skips Montage_Windup)
  Routes to    UFP_GA_Leap::ShouldSkipWindup — Blueprint skips PlayMontageAndWait
               for Montage_Windup when true.
  Trade-off    Enables instant escape use but imposes a cooldown on the skill.
               The cooldown is intended to be implemented via a GE driven by the
               CooldownDuration passive accumulator. Until then, set a fixed
               cooldown in the BP or GE class.
               CooldownDuration nodes let the player invest to reduce that penalty.
  Connections  Major node. NoWindup.1 gates CooldownDuration.1.


--------------------------------------------------------------------------------
  HEAT COST  (6 nodes)
  WIRED 2026-11-01 via the native skill cost (Skill Library BaseHeatCost)
--------------------------------------------------------------------------------
  Node tags    SkillTree.Leap.HeatCost.1  →  .6
  Effect tag   SkillPassive.Leap.HeatCost
  Magnitude    TBD per node  (each node adds accumulated heat generated per cast)
  Routes to    UFP_DamageGameplayAbility::GetFlatHeatCostBonus — added to the
               level-scaled BaseHeatCost before the cost stats. Requires
               SkillPassiveRootTag = SkillPassive.Leap on BP_GA_Leap, and either a
               BaseHeatCost in Leap's Skill Library entry or no Cost GE on the GA.
  Connections  TBD. Suggest gating HeatCost.1 behind ExplosiveLanding.1 to make
               it a cost branch for the power upgrade.
  Notes        Heat cost is a resource expenditure on each use. Higher heat cost
               in exchange for other bonuses (e.g. damage, range) is the intended
               design direction. Magnitudes to be decided with heat system design.


--------------------------------------------------------------------------------
  COOLDOWN DURATION  (4 nodes)

  Node tags    SkillTree.Leap.CooldownDuration.1  →  .4
  Effect tag   SkillPassive.Leap.CooldownDuration
  Magnitude    TBD per node  (negative seconds of cooldown reduction per node)
  Routes to    UFP_GA_Leap — NOT YET WIRED. When implemented, the base cooldown
